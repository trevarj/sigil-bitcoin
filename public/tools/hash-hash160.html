Hashing

HASH160

Compute RIPEMD160(SHA256(bytes)), the 20-byte hash used by P2PKH, P2SH, and P2WPKH address flows.

How To Use It

Paste hex-encoded bytes. The result is a 20-byte hash encoded as hex.

Example

0279be667ef9dcbbac55a06295ce870b07029bfcdb2dce28d959f2815b16f81798

Runs locally in WebAssembly

Live Tool

Inputs stay in this browser tab. No transaction broadcast or remote Bitcoin API calls are used.
