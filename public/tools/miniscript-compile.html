Miniscript

Compile Miniscript

Parse Miniscript, inspect its type flags, and compile it to script bytes.

How To Use It

Paste a Miniscript expression using supported fragments such as pk, older, and_v, multi, thresh, and Taproot-only multi_a.

Example

multi_a(1,0279be667ef9dcbbac55a06295ce870b07029bfcdb2dce28d959f2815b16f81798,03f028892bad7ed57d2fb57bf33081d5cfcf6f9ed3d3d7f159c2e2fff579dc341a)

Runs locally in WebAssembly

Live Tool

Inputs stay in this browser tab. No transaction broadcast or remote Bitcoin API calls are used.
