Hashing

Tagged hash

Compute a BIP340-style tagged hash for Taproot and Schnorr related domains.

How To Use It

Paste message bytes as hex and provide the tag string, such as TapTweak or BIP0340/challenge.

Example

Tag: TapTweak; bytes: 32 zero bytes

Runs locally in WebAssembly

Live Tool

Inputs stay in this browser tab. No transaction broadcast or remote Bitcoin API calls are used.
